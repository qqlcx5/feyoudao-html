## 📖 项目简介

本仓库精选并沉淀了大量趣味前端交互作品与视觉特效，适合前端初学者提升动手能力、开拓视觉创意灵感或作为页面组件特效参考。

---

## 📂 特效模块分类

- 🎆 **视觉与粒子特效**：`fireworks`（新年烟花动效）、`flying-fish`（灵动飞鱼动画）
- 🕶️ **3D 体验**：`3d/` 三维立方体旋转、空间全景展示
- 💖 **节日与表白专题**：`520表白/` 浪漫互动页面
- 🎮 **经典小游戏**：`游戏/` 贪吃蛇、2048、俄罗斯方块纯 JS 实现
- 🏢 **高仿精品官网**：`静态官网/` 经典互联网企业静态官网像素级手写还原

## 🚀 本地体验

无需复杂构建流程，直接双击任意目录下的 `index.html` 或使用 VS Code 插件 **Live Server** 即可即时体验。
